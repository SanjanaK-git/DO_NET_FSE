# Git Ignore Demo

## Objective
Demonstrate the use of the `.gitignore` file to ignore unwanted files and folders.

## Ignored Items
- All `.log` files
- `logs` folder
- `log` folder

## Git Commands Used

```bash
git init
git status
git add .
git commit -m "Added .gitignore"
git push -u origin main
```
